===================
metagraph_workflows
===================

This package provides workflows for the `metagraph framework
<https://metagraph.ethz.ch>`_

See the `corresponding section <https://metagraph.ethz.ch/static/docs/workflows.html>`_ in the metagraph documentation.

The experimental count-aware differential assembly pipeline is documented in
``differential_assembly/README.md``. It is intended for the
``count_diff_assem`` branch and is invoked directly with Snakemake.
