# Contributing

Open a pull request against `master`. The developer notes in the README cover Docker builds and releases.

For documentation and user-facing text, follow the [writing principles](https://github.com/ratschlab/writing-rules/blob/7e477ce0c6c33094e401c1cefca884af4746fe14/guides/PRINCIPLES.md) and run the [text check](docs/writing/README.md). Verify factual claims, defaults and examples against the implementation.

For pull requests, reviews and commit messages, see the [engineering communication guide](https://github.com/ratschlab/writing-rules/blob/7e477ce0c6c33094e401c1cefca884af4746fe14/guides/ENGINEERING.md).

Before proposing a new feature, option, flag, endpoint or API field, check it against the [stewardship principles](https://github.com/ratschlab/writing-rules/blob/7e477ce0c6c33094e401c1cefca884af4746fe14/guides/STEWARDSHIP.md).
