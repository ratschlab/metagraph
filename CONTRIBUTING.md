# Contributing

Open a pull request against `master`. The developer notes in the README cover Docker builds and releases.

For documentation and user-facing text, follow the [writing principles](https://github.com/ratschlab/writing-rules/blob/5fe98632f7399e0dd1006cc20ff38f90c9bd823e/PRINCIPLES.md) and run the [text check](docs/writing/README.md). Verify factual claims, defaults and examples against the implementation.

For pull requests, reviews and commit messages, see the [engineering communication guide](https://github.com/ratschlab/writing-rules/blob/5fe98632f7399e0dd1006cc20ff38f90c9bd823e/ENGINEERING.md).
