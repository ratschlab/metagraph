# Contributing

Open a pull request against `master`. The developer notes in the README cover Docker builds and releases.

For documentation and user-facing text, follow [AGENTS.md](AGENTS.md#writing-for-people), the [shared principles](https://github.com/ratschlab/writing-rules/blob/cd4988d183077ebc769eb1204fca1c5aabe8f23d/PRINCIPLES.md), and the [text-check instructions](docs/writing/README.md). Keep factual claims and examples consistent with the implementation.
