# Contributing

Open a pull request against `master`. The developer notes in the README cover Docker builds and releases.

For documentation and user-facing text, follow the [writing principles](https://github.com/ratschlab/writing-rules/blob/fe9defad9a3552bce895c3720243adc61178d6ce/PRINCIPLES.md) and run the [text check](docs/writing/README.md). Verify factual claims, defaults and examples against the implementation.

For pull requests, reviews and commit messages, see the [engineering communication guide](https://github.com/ratschlab/writing-rules/blob/fe9defad9a3552bce895c3720243adc61178d6ce/ENGINEERING.md).

Before proposing a new feature, option or API field, check it against the [stewardship principles](https://github.com/ratschlab/writing-rules/blob/fe9defad9a3552bce895c3720243adc61178d6ce/STEWARDSHIP.md).
