# Contributing

Open a pull request against `master`. The developer notes in the README cover Docker builds and releases.

For documentation and user-facing text, follow [AGENTS.md](AGENTS.md#writing-for-people), the [shared principles](https://github.com/ratschlab/writing-rules/blob/5fe98632f7399e0dd1006cc20ff38f90c9bd823e/PRINCIPLES.md), and the [text-check instructions](docs/writing/README.md). Keep factual claims and examples consistent with the implementation.
